# flat-assembler-examples

A collection of simple Flat Assembler (FASM) code examples, including Windows API integration, basic math, and control flow.

## Directory Structure

```text
flat-assembler-examples/
├── 01-basics-and-math/
│   ├── basics_and_math.ASM
│   └── pointers_functions.ASM
├── 02-control-flow/
│   ├── array_loop.ASM
│   ├── array_sum.ASM
│   ├── condition_else_if.ASM
│   └── condition_if_else.ASM
└── 03-windows-api/
    ├── messagebox_and_shellexecute.ASM
    └── simple_sound_recorder.ASM
```
## Requirements

[Download Flat Assembler (FASM)](https://flatassembler.net/)

# Contributing

You can open a pull request for contributing.
When adding an example, please keep it:

- Small and focused on one concept
- Easy to read
- Properly commented
- Consistent with the existing directory structure
